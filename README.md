# Reservas Já

Aplicação para gerenciamento de reservas, desenvolvida com Next.js (15) com typescript e tailwindcss.

## Pré-requisitos

- Node.js v22.17.0

## Instalação

1. Clone o repositório:
    ```bash 
    git clone https://github.com/JoaoVitor-Web-Developer/reservas-frontend.git
2. Acesse o diretório do projeto:
    ```bash
    cd sua-pasta
3. Instale as dependências:
    ```bash 
    npm install
4. Inicie a aplicação:
    ```bash
    npm run dev
## Uso

Acesse a aplicação em `http://localhost:3000` para visualizá-la no navegador.
